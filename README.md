# PCB Enclosure Function
This PCB Enclosure function is each button plunger commands what the LED does with each light connected to one button.
## 3D Design
The 3D design was built in Autodesk Fusion and consist of a simple design that gets the job done.
There is 3 holes for the LEDs with 3 button plungers and a hole that opens to the OLED screen.
